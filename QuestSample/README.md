# Quest 3 standalone sample

Unity project for a Meta Quest 3 APK that renders a Gaussian splat with head tracking, smooth locomotion, and snap turn.

Open this folder in Unity 6.2 (Add project from disk). Setup steps, the skybox-only failure, and splat-count limits are in [QUEST3_STANDALONE.md](../QUEST3_STANDALONE.md).
